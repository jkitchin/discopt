# Small MINLPLib instances SCIP solves and discopt does not (2026-10-25)

Round 2 of the screen in `docs/dev/scip-wins-2026-10-21.md`, tracked in #1941 (the round-2
tracking issue of #1913). Source of `discopt_benchmarks/config/suites/scip_wins.txt`.
Reproduce with `discopt_benchmarks/scripts/scip_wins_screen.py`; since this round the script
writes `<out>/candidates_tl<T>.txt` itself, so stage 2 reads stage 1's list directly.

## Setup

- discopt at `dcf63d5`, the head of #1943, which graduates `DISCOPT_KERNEL_PSEUDOCOST`. Release
  build; `discopt.__file__` was checked to be this tree on every solve. POUNCE 0.13.0, the
  version CI builds from git `main`.
- SCIP 10.0 via pyscipopt 6.3.0, which reads `.nl` natively.
- Both solvers use `gap = 1e-4`. SCIP runs single-threaded (its default) with a 4 GB memory
  limit. Each solve runs in its own subprocess with a hard timeout of `T + 30` s. Times are
  solve wall time; the import is not counted.
- Panel: every MINLPLib instance with an `.nl`, ≤ 50 variables, ≤ 50 constraints and a proven
  status (`gap == 0` in `instancedata.csv`, or `=inf=` in `minlplib.solu`): **292 instances**,
  the same panel as 2026-10-21. Oracle: MINLPLib `primalbound` (rel/abs 1e-4 / 1e-6).
- Linux container with 4 cores.

## Item 2 (tln) in detail

The measurements are in the #1941 comment of 2026-10-25. In short:

**SCIP closes tln4 at the root through separation.**

| SCIP setting | tln4 root bound (opt 8.3) |
|---|---:|
| default | 8.3 |
| presolve only | 3.05 |
| without the RLT separator | 5.90 |

discopt lifts tln with the exact integer-bilinear lift into a pure MILP. Its LP relaxation
gives a root bound of 1.73 on tln4.

**Lift vs unlifted over all 54 MINLPLib instances where the lift is adopted** (30 s):
- Soundness: 0 problems in either arm.
- Certified: lift 47, unlifted 44.
- Neither route dominates:
  - ex1263–66 certify only lifted.
  - tln4 certifies only unlifted (1.3 s).
  - tln5/6 bounds are 9.8 / 10.5 unlifted vs 5.7 / 6.2 lifted.
- A cheap-first probe (`DISCOPT_IPX_CHEAP_FIRST`), simulated from that panel, adds one
  certificate for +13–28 % total wall, so it stays off.
- The lever is RLT-strength root cuts on this class.

## Caveats

- Each solver ran once per instance, with no repeats and no spread, so read the times as
  orders of magnitude. The suite's selection does not depend on timing precision: SCIP takes
  ≤ 5 s, and discopt fails at a 120 s cap.
- SCIP's statuses were checked against the oracle. Its own certificates were not re-verified
  independently.
- The panel is ≤ 50 vars/cons, the same as round 1. #1913 suggests widening later rounds to
  `--max-vars/--max-cons 200` and adding QPLIB.
